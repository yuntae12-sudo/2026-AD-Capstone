**실행은 완료됐지만 정책 학습은 실패했다.** 학습 장면에서도 업데이트 직후 경로 통과율이
무너졌고, 최종 모델은 제안 경로 자체가 물리적으로 불가능하다. 검사 기준을 완화하거나 같은
설정으로 장시간 학습을 연장하는 것이 우선 해결책이라는 근거는 없다.

대상은 `outputs/pure_sac_stable_20261117`의 고정 소스 `1d6ea21` 실험이다.
seed0/1/2 모두 BC0, teacher replay0이며 최종 SAC 업데이트는 각각10,191/10,003/10,017회다.
2026-11-17 22:36 KST에 학습·평가·비교가 완료됐다. 이번 작업은 분석·재실행 시각화만
수행했으며 learner, sampler, 보상, 물리 검사, PD 및 원본 결과를 수정하지 않았다.

## 1. 최종 평가와 악화 시점

validation은 **고유 장면8개 × KEEP/FOLLOW = 16회**, 이를 seed별로 반복했다.
48회가 독립된48개 장면이라는 뜻은 아니다.

| 평가 | 성공률 | 충돌률 | 경로 거절률 | 제동 개입률 | 정지 비중 |
|---|---:|---:|---:|---:|---:|
| Rule-based KEEP | 50% | 50% | 28.65% | 27.15% | 36.33% |
| Rule-based FOLLOW | 37.5% | 50% | 15.84% | 14.36% | 35.73% |
| SAC KEEP/FOLLOW, 각 seed | 0% | 100% | 100% | 100% | 75% |

SAC의 모든 최종 평가 tick은 `UNRESOLVED_SWEEP → EMERGENCY`였다.
경로가 수락되지 않아 PD가 SAC 제안 경로를 추종한 구간은 없다.
세 모델의 출력이 동일해서 결과가 같은 것이 아니라, 모두 거절되어 같은 fallback 제어로
움직인 결과다. checkpoint 해시와 reset probe의 raw_u는 seed별로 다르다.

초기5,000개는 초기 actor의 확률 표본으로 자체 수집한 warmup이다.
아래는 실제 train trace의 유효 전이 전수 집계이며, 성공한 episode만 골라낸 값이 아니다.

| Seed | warmup 경로 통과 | 이후 경로 통과 |
|---|---:|---:|
| 0 | 3,209 / 5,000 (64.18%) | 1 / 10,191 (0.0098%) |
| 1 | 3,205 / 5,000 (64.10%) | 1 / 10,003 (0.0100%) |
| 2 | 3,247 / 5,000 (64.94%) | 0 / 10,017 (0%) |

5,000개 시점의 결정적 validation은 세 seed 모두 성공12.5%, 거절40.18%, 정지48.98%였다.
10,000개 시점부터 최종 결과와 같은 성공0%, 거절100%, 정지75%가 나타났다.
보상이 좋아지면서 정지하는 패턴이 아니라 **보상과 주행 성능이 함께 악화**됐다.

## 2. 첫 업데이트부터 경로가 깨지는 직접 증거

seed0의5,001번째 전이는 업데이트 전 정책으로 생성돼 통과했다.
업데이트1회 후 생성한5,002번째 전이는 다음 항목을 위반했다.

- 접선/횡가속도, 곡률, 접선 jerk, 곡률 변화율.
- raw_u 최대 절댓값은 약0.0103에 불과하지만 보간 경로의 vector 가속도는
  최소218.34m/s², vector jerk는 최소15,272.27m/s³였다.
- 같은 앵커에서 raw_u=0인 진단용 기준 경로는 reference 운동학 검사를 통과했다.
  이 비교는 물체/도로를 제외한 운동학 검사이며 전체 주행 성공을 인증하지 않는다.

seed1도 첫 업데이트 후 vector 가속도173.83m/s², jerk11,292.73m/s³로 운동학 검사에
실패했다. seed2는 주변 차량을 포함한 원래 검사에서 `UNRESOLVED_SWEEP`이 먼저 반환됐지만,
주변 차량을 제외한 reference 검사에서도 가속도·곡률·jerk 위반이 확인됐다.

이 측정은 저장된 원본 sampled action을 사용한다. 가중치를 재학습해 원본과 동일하다고
가정하지 않았다. `first-updates-geometry.json`에5,001~5,005번째 전이의 결과를 보존했다.

## 3. 최종 모델: 학습 장면과 새 장면 모두 실패

GPU 정책 추론과 원래 CPU 검사로 각 seed의 validation16개 reset 전체와,
실제로 수집한 train 쌍 중 manifest 순서의 첫16개 reset을 조사했다.
각 상태에서 평균, 고정 seed 확률 표본2개, raw_u=0 기준 경로를 검사했다.
총96개 seed/state 조합,384개 경로다. 표본2개를 통과율 gate로 해석하지 않는다.

| Probe | 수락 / 검사 수 |
|---|---:|
| 최종 모델 평균, train | 0 / 48 |
| 최종 모델 평균, validation | 0 / 48 |
| 최종 모델 확률 표본, 두 split 합계 | 0 / 192 |
| raw_u=0 기준 경로, 두 split 합계 | 60 / 96 |

최종 평균 경로는96개 모두 `UNRESOLVED_SWEEP`이었다. 새 장면에만 실패하는 일반화 문제로
설명할 수 없다. train reset 일부와 학습 trace에서도 실패했기 때문이다.

평균 raw_u 최대 절댓값은 상태별 약18.62~37.71, 앵커에서 가장 먼 경로점은 약346~737m다.
1ms 간격으로 보간 경로를 조사한 최대 속도는 상태별 **6,637~19,881m/s**였다.
이는 실제 차량 속도가 아니라 제안 경로의 미분값이다. 격자 최대값은 연속 최대값의
하한이며, 이 하한만으로도 속도 상한15m/s를 훨씬 넘는다.

`_reference_kinematics`는 속도와 주변 차량 속도를 바탕으로 sweep 간격을 정한다.
필요 간격이0.002초보다 작으면 세부 운동학/충돌 검사 전에 `UNRESOLVED_SWEEP`을 반환한다.
따라서 `violations=[]`가 물리 한계 위반이 없다는 뜻은 아니다.
여기서 sweep 하한을 낮추는 것은 비정상 경로를 유효한 경로로 만들지 못한다.

코드상 mean은30×2개의 독립 출력이고, 상관행렬B는 탐색 noise에만 적용된다.
경로 변환은 `기준 운동 + 3·시간²·raw_u`다. 평균 출력에 작은 불연속적인 변화가 생겨도
0.1초 간격 경로의 가속도/jerk가 크게 변할 수 있다. 최종 표본의 raw_u 좌표별 표준편차
최대값은 상태별 약0.00000266~0.00133으로, 크게 망가진 평균을 복원할 크기가 아니다.
**합성 sampler 검사를 통과했다는 사실은 학습된 mean의 유효성을 보장하지 않는다.**

## 4. Q와 실제 결과의 불일치

최종 mean에 대한 min(Q1,Q2)는 probe 전체에서 약+14.68~+16.10이었다.
seed0의 빠른 KEEP 장면에서는 약+15.21이지만 재실행한 실제 결정적 주행의
gamma0.99 할인 return은 약−17.02였다. 저속 FOLLOW도 Q약+15.12, 실제 약−16.96이다.

Q는 entropy가 포함된 확률 정책을 대상으로 하고 위 return은 결정적 주행 결과이므로
둘의 차이를 정확한 Q calibration 오차라고 주장하지 않는다. 다만 거절되는 큰 mean에
낙관적인 값을 부여하는 증거이며, **유한한 loss/Q가 좋은 정책을 뜻하지 않음**을 보여준다.
LayerNorm은 이전 수치 발산을 줄였지만 정책 붕괴까지 해결하지는 못했다.

mean의 시간 구조·업데이트 크기·Q의 행동 방향 gradient가 각각 얼마나 기여했는지는
분리 실험이 필요하다. 한 가지 원인만으로 전체 실패가 증명됐다고 단정하지 않는다.

## 5. 실제 Waymax GIF와 충돌 접촉

두 GIF 모두 seed0 최종10,191회 업데이트 모델과 Rule-based를 같은 초기 상태에서
종료까지 실행했다. CPU inference 시각화이며 GPU 원평가 자체의 영상은 아니다.
SAC의 episode 길이, 종료 원인, 거절 사유별 횟수, return은 GPU 평가와 대조해 일치했다.
이 집계 일치를 모든 중간 좌표의 bit 단위 일치라고 해석하지 않는다.

접촉은 최종 OBB 중첩 차량 ID와 이전 상대 위치로 확인했다. 이 결과가 책임이나 충돌의
불가피성을 증명하지 않는다. 주변 차량은 WOMD 로그를 재생하므로 ego의 제동에 반응하지 않는다.
빨간 점선은 거절된 제안 경로이고 초록 궤적이 실제 주행이다. 먼저 종료한 화면은
`held`로 표시하며 이후 움직임을 만들어내지 않는다.

## 6. 다음 개발의 우선순위

1. 짧은 업데이트 진단부터 수행한다. 같은 상태에서 업데이트0/1/10/100회 뒤 mean의
   운동학 위반과 경로 통과율, Q gradient를 비교해 첫 업데이트 붕괴를 재현·차단한다.
2. raw_u/미래3초30점·순수 SAC 조건을 유지하며 mean의 시간 구조와 출력 민감도를 개선할
   방안을 기준서와 대조한다. 학습률·mean 구조 등을 바꾼다면 별도 실험 개정으로 기록한다.
   BC/teacher replay를 주 실험에 되돌리거나 검사 한계를 완화하지 않는다.
3. Q가 거절 경로를 선호하는 문제와 제동 후 보상이 비슷해지는 구간을 분리 진단한다.
   짧은 업데이트 후에도 실제 유효 경로와 개선 신호가 유지되는지 확인한 다음 장시간 학습한다.
4. 현재8개 validation 결과를 고정 보존한다. 로그 차량의 비반응성과 초기 정지 장면의
   영향을 별도 분석하고, 추가 평가 장면은 별도 실험으로 구성한다.

이번 작업에서는 새 장시간 학습을 시작하지 않았다. 현재 결과를 성공 사례로 사용하거나
정책이 수렴했다고 판단하지 않는다.

```bash
  --run outputs/pure_sac_stable_20261117 \
  --manifest outputs/sac_readiness_20261116/inventory/eligible_manifest_reset_v2.json \

```

확인했다. 원본 학습/평가/체크포인트와 새 진단은 서로 다른 디렉터리에 보존한다.
