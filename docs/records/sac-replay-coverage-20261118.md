# 현재 정책과 replay 분포 점검 및 평균 출력 배율 비교

2026-11-18. [Q 반례 진단](sac-q-audit-20261118.md)의 후속 작업이다.
현재 정책의 행동에서 나타나는 Q 과대평가를 데이터 분포와 함께 확인하고,
승인된 B 평균 비교 범위에서 선형 배율 하나를 바꾸는 제한 실험을 수행한다.
대조군 경험 복원과 두 후보의 각1,000회 온라인 학습·실제 주행 검증을 완료했다.
**분포 차이는 줄었지만 Q 과대평가와 충돌은 해결하지 못했으므로 두 후보 모두
채택하지 않는다.** 기존 본 실험 가중치는 보존했고, 별도 후보만 새로 학습했다.

첫 후보의 최근100개 행동 겹침은95%로 늘었지만 warmup 겹침은14.72%였고, 고정된
첫 train 반례의 현재 평균 Q는+0.1095, 실제 보상은-20.014로 과대평가가 남았다.
이를 확인한 뒤 배율을 다시10분의1로 낮춘 `mean_gain=0.0012098536225957168`
(이동 상태 유효 배율0.0001) 후보를 같은1,000회 예산으로 추가했다.
추가 후보가 사전에 첫 후보와 동시에 지정돼 있었다고 주장하지 않는다. 후보 선택에
사용한 자료는 개발 자료이며, 이번 비교는 이 두 보완 후보로 제한한다.

## 고정한 비교 조건

- 대조군: `aligned-online1000`, seed0·자체 warmup5,000개·온라인1,000회.
- 후보: `mean_gain=0.12098536225957167`에서 `0.012098536225957168`로 변경.
  `mu=g*c*B@(gain*h)`에서 g=1일 때의 유효 선형 배율은0.01→0.001이다.
  초기 mean은 두 모델 모두0, 초기 covariance도 같아 동일 자체 warmup을 재사용한다.
- gain은 양수이고 B는 full-rank다. 출력의60개 자유도와 무제한 범위는 유지되며
  action clipping/제약을 추가하지 않는다. 출력이 움직이는 정도를 줄여 Q 학습이
  현재 정책의 행동을 따라갈 수 있는지 시험하는 가설이며 성공을 전제하지 않는다.
- actor/critic 학습률, 업데이트 비율·순서, uniform replay minibatch256, sigma/entropy,
  reward, checker, PD, train/validation manifest, seed와 초기 learner RNG를 유지한다.
  각 신규 전이를 넣은 뒤 SAC update1회를 수행한다. BC/teacher replay는 사용하지 않는다.
- 기존 직접 평균 출력 규약의 주 실험으로 채택한 것이 아니라, 이미 승인된 B 평균의
  별도 비교다. `pure_sac_v1.json`과 모델 기본 설정은 바꾸지 않는다.

## 분포 점검 방법

기존 대조군은 온라인 replay를 저장하지 않아, 기록된 raw proposal을 실제 Waymax에
다시 적용해 신규1,000개 경험의 관측을 복원한다. 최초 anchor·실행 제어·보상·검사·
종료가 원래 기록과 일치해야 사용하며, 원본 배열을 직접 읽은 자료와는 구분한다.
후보는 실제 학습 replay를 저장하고 신규 raw action이 실행 로그와 정확히 같은지 검사한다.

각 과거 관측에서 **마지막 정책의** mean과 sigma를 계산한 뒤 저장된 행동의
`epsilon=(g*B)^(-1)*(u_recorded-mu_current)/sigma_current`를 구한다.
epsilon은60차원이므로 RMS가 `sqrt(chi2.ppf(.95,60)/60)` 이하인 비중을 계산한다.
이는 같은 관측에서 과거 행동과 현재 분포가 얼마나 겹치는지 보는 지표다.
Gaussian은 무제한 support를 가지므로 이를 엄밀한 support 부재, 새로운 행동의
충분한 데이터 확보, 또는 신뢰구간이라고 부르지 않는다. 좋은 정책으로 변화해도
겹침이 줄 수 있으므로 이 값만으로 개선을 판정하지 않는다.

warmup·온라인 전체·마지막100개를 구분하고, 기록 행동의 terminal Q 오차와 현재
평균 행동의 Q 차이도 함께 집계한다. 마지막 열은 실제 대체 행동을 실행하기 전에는
정답 오차로 간주하지 않는다. 모델별 신규 주행 상태는 달라지므로 동일 관측 대조는
공통 warmup과 고정된 두 train 반례에서 수행한다.

샘플링 순서는 seed0의 NumPy RNG와 매 전이마다1회 `Replay.sample(256)` 호출로
재구성한다. 실제 Replay.sample과 RNG 일치를 테스트하고, 후보의 저장된 최종 RNG와도
대조한다. 대조군의 과거 sampling index가 직접 기록되어 있었다고 주장하지 않는다.

1,000회·256,000개 추출 중 warmup233,361개(91.1566%), 신규22,639개(8.8434%)였다.
매 update 당시 최근 최대100개 신규 전이는4,454번(1.7398%) 추출됐다. 신규1,000개 중
22개는 종료 시점까지 한 번도 추출되지 않았다. 마지막 replay 자체의 신규 비율은
1,000/6,000=16.67%이며, 전체 학습 동안의 추출 비율과 혼동하지 않는다.
이는 uniform replay의 결과이며 그 자체로 구현 버그라는 뜻은 아니다.

### 완료된 세 모델의 분포 점검

| 과거 행동이 마지막 정책95% 영역에 속하는 비중 | 대조군 | gain÷10 | gain÷100 |
|---|---:|---:|---:|
| 공통 warmup5,000개 | 0% | 14.72% | 88.68% |
| 모델별 신규1,000개 | 1.1% | 37.5% | 52.4% |
| 모델별 마지막100개 | 11% | 95% | 83% |

이 표는 비교 방향이 중요하다. 과거 행동이 현재 분포 안에 들어가는 비중이지, 현재
표본의 해당 비중이 과거 데이터로 충분히 설명된다는 뜻은 아니다. 역방향 점검에서
공통 warmup 관측의 현재 **평균**이 초기 정책95% 영역에 들어가는 비중은 두 모델
모두0%였다(gain÷100은100%). 초기 sigma 단위 평균 이동량 RMS의 중앙값은5.4966→1.5275였고,
초기 정책을 기준으로 한 정확한 Gaussian KL의 중앙값은919.20→82.79→4.43nats였다.
gain÷100의 평균 이동량 RMS 중앙값은0.3471이었다. 평균이95% 영역 안에 있다는
사실도60차원 공간에서 그 평균 부근의 실제 학습 표본이 충분하다는 보장은 아니다.
초기 분포의95% 반지름은RMS1.14806이다. 초기 기록 자체를 같은 방법으로 계산하면
95.3%가 이 영역에 들어가며, 표준화 epsilon RMS는1.00168이었다.

warmup의 정지 관측은3,347/5,000개였다. 대조군 신규 경험은13개 고유 장면에서1,000개,
이 중 정지 관측611개였다. 첫 후보는12개 고유 장면·정지599개, 두 번째 후보는
12개 고유 장면·정지619개였다. 이 값은 제안 전
관측 속도<0.1m/s의 비중이며, 주행 평가의 post-step 정지 비중과 구분한다.

대조군의 신규 큰 벌점 terminal11개는 총313번 추출됐고 기록 행동 Q의 평균 절대
오차는4.05였다. 마지막100개에 들어 있는 terminal2개는 총7번만 추출됐고 오차는
15.59였다. 첫 후보의 마지막100개에는 해당 terminal이1개 있었고1번 추출됐으며
오차는19.03이었다. 늦게 들어온 실패 경험의 적합도가 낮은 관찰이며, 전체 실패를
단일 원인으로 설명하거나 임의 replay 재가중을 승인하는 근거로 취급하지 않는다.

## 실제 검증 범위

1. warmup62개 terminal target 적합도와 현재 정책 행동의 Q 차이를 모델별로 비교한다.
2. 이전에 선정한 train 두 상태(index1405/1277)를 그대로 복원해 각 후보의 현재 평균
   행동을 실제로 실행한다. 후보에 유리한 새로운 상태로 교체하지 않는다.
3. 같은 validation 두 장면의 KEEP/FOLLOW4개를 실행한다. 평균0 초기 정책도 함께
   평가해, 초기 성능으로 돌아간 것과 학습을 통한 개선을 구분한다.
4. 종료 직전 상태에서 후보 경로의 Q와 실제 terminal reward를 대조한다.
   Q 오차가 줄어도 주행이 실패하면 성능 문제 해결이나 모델 채택을 선언하지 않는다.

첫 후보(gain÷10)는 두 고정 train 반례에서 현재 평균 행동이 여전히 같은 제동·충돌로
이어졌고, Q 과대평가가 남았다. validation4episode도 모두 충돌했다. 빠른 장면의
KEEP/FOLLOW는 각각34tick, 저속 장면은각각25tick에 충돌했다. 같은 조건으로 재평가한
미학습 평균0 정책은 빠른 두 주행에서 목표 도달, 저속 두 주행에서 충돌했다.
따라서 첫 후보는 분포 지표 일부만 개선됐으며 주행 보완으로 채택하지 않는다.

## 고정 train 반례의 실제 Q 오차

동일 warmup 관측 두 개에서 현재 평균을 실행했다. 세 모델 모두 거절→긴급 제동→충돌,
bootstrap=False이며 아래 실제 보상과 같은 다음 관측으로 끝났다. 그러므로 이 두
행동의 정답은 학습된 target Q가 아닌 실제 terminal reward다.

| 고정 replay index | 실제 보상 | 대조군 Q | gain÷10 Q | gain÷100 Q |
|---|---:|---:|---:|---:|
| 1405 / KEEP | -20.014 | +0.145 | +0.109 | -2.980 |
| 1277 / FOLLOW | -20.017 | +0.093 | -0.025 | -2.526 |

gain÷100에서도 약17점의 과대평가가 남았다. 두 개 반례로 전체 정책의 보정 오차를
추정하지는 않지만, “평균을 초기 분포 가까이 가져오면 현재 행동의 Q가 충분히 맞는다”는
주장은 이 결과로 지지되지 않는다. 공통 warmup의 큰 벌점 terminal44개의 **기록된 행동**
Q MAE도0.200→0.497→0.707로, 모든 적합도가 좋아진 것도 아니다.

## 동일 장면의 주행과 종료 직전 Q 검증

두 validation 장면×KEEP/FOLLOW를 초기 관측·지도 동일성 검증 후 비교했다.
아래 거절·제동·정지율은 episode 비율이 아니라 합산 tick 비율이다. 종료가 빨라지면
분모와 관측 시간이 바뀌므로 단독 성능 순위로 사용하지 않는다.

| 모델 | 목표 도달 / 충돌 | 전체 tick | 거절률 | 제동률 | 정지율 | 평균 return |
|---|---:|---:|---:|---:|---:|---:|
| 대조군 | 0/4 · 4/4 | 154 | 79.87% | 65.58% | 25.32% | -20.326 |
| gain÷10 | 0/4 · 4/4 | 118 | 83.05% | 72.88% | 25.42% | -20.286 |
| 미학습 평균0 | 2/4 · 2/4 | 216 | 26.85% | 21.30% | 10.19% | -10.015 |
| gain÷100 | 0/4 · 4/4 | 150 | 66.67% | 58.67% | 22.67% | -20.282 |

gain÷100은 빠른 장면 KEEP/FOLLOW에서 각각45tick, 저속 장면에서 각각30tick에
충돌했다. 초기 정책의 빠른 두 주행 성공도 보존하지 못했다. 두 후보의 조금 덜 음수인
return이나 일부 비율 개선을 성공으로 해석하지 않는다.

각 모델의 자체 평균 주행에서 마지막 실행 직전 상태4개를 선택했다. 매 상태에서
평균과 확률 표본8개를 실제 실행했으며 모두 terminal 충돌이라 bootstrap 없이 실제
reward와 대조할 수 있었다. 모델별 도달 상태가 달라 **고정 상태의 대조 실험은 아니며**,
고정 상태 대조는 위 train 반례 두 개다. 표본32개는 독립 주행32회가 아니다.

| 모델 | 마지막 상태 평균 행동 Q MAE (4개) | 확률 행동 Q MAE (32개) |
|---|---:|---:|
| 대조군 | 20.130 | 20.012 |
| gain÷10 | 19.999 | 19.941 |
| gain÷100 | 16.503 | 15.420 |

평균과 확률 행동 모두 과대평가가 남았다. 따라서 “평균 평가만의 문제”로 설명하거나
확률 정책은 안전하다고 판정할 수 없다. 이번 결과는 seed0의1,000회 제한 진단이며
완전한 수렴 실험이 아니다. 반복 사용한 validation은 개발 자료이고 별도 test가 아니다.

## 판정과 다음 작업

- 두 배율 후보는 채택하지 않는다. 기본 설정·보상·안전검사·PD·본 실험 가중치를 유지한다.
- 단순 배율 축소를 추가 반복하기보다, 동일 관측에서 실제 결과가 같은 기록 행동·현재
  평균·현재 확률 행동에 대한 Q 일반화 실패를 분리한다. 별도 진단 자료의 행동을
  학습용/검증용으로 나눠 critic 적합과 일반화를 확인하는 것이 다음 제한 실험이다.
- replay 비율 변경이나 보수적 Q 손실 추가는 이번에 시행하지 않았다. 이런 학습 규약
  변경이 필요하면 별도 비교안으로 명시해야 하며, 이번 실패를 근거로 조용히 적용하지 않는다.
- 실제 주행 회귀를 통과하기 전 장기3-seed 학습을 다시 시작하지 않는다. 개선된 정책을
  확보한 뒤 동일 조건 Rule-based 비교와 별도 장면 평가를 진행한다.

## 산출물

원시 자료는 `outputs/sac_replay_coverage_20261118/`에 저장한다.
`control-replay`는 재현 자료, `gain001-online1000`은 새 제한 학습이다.

- `candidate-evaluation/`, `candidate2-evaluation/`: 주행 원본과 집계.
- `candidate-terminal-q/`, `candidate2-terminal-q/`: 종료 직전 후보별 Q와 실제 결과.

  통과한 종합 결과. `overlap.png/svg`, `fast-KEEP.gif`도 저장했다. GIF는 대조군과
  gain÷100의 동일 빠른 KEEP 장면이며 Rule-based 최종 비교 영상은 아니다.
- `summarize_trials.py`: 이번 자료 집계·그림/GIF 생성 스크립트. 출력 폴더가 이미 있으면
  덮어쓰지 않는다. 원본 실험은 각 `*-launch.json`에 실제 명령을 기록했다.

재사용 진단 도구는 `scripts/reconstruct_sac_diagnostic_replay.py`와
`scripts/audit_sac_replay_coverage.py`다. 온라인 제한 실행에는 `--mean-gain`과
`--save-replay`, 고정 반례에는 `--reference-cases`, 종료 직전 검사에는
`--terminal-only --continuations 0`을 추가했다. 기본 실행 동작은 유지한다.
