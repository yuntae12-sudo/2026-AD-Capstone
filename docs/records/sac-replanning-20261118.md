# 같은 상태에서 경로 재계획과 PD 추종 분리

2026-11-18. 이번에 조사한 주행의 주요 실패는 **가상 PD 실행 전에 제안 경로가
도로/운동 검사를 통과하지 못하는 것**이었다. 실제 선택된 경로의 한 스텝 추종 오차는
작았다. PD 게인을 먼저 바꿀 근거는 얻지 못했으며, 상태별 유효 경로 생성과 학습을
다음 보완 대상으로 좁혔다. 모든 장면의 PD 안정성을 증명한 결과는 아니다.

## 진행 위치와 범위

[전체 개발 진행표](sac-development-progress.md#현재-위치--2026-11-18)에 현재 단계와
2~3주 일정 운영 기준을 갱신했다. 환경·학습·평가 구현 및 첫3-seed 실험은 완료했지만,
안정적인 순수 SAC 주행 성능과 별도 장면의 최종 검증은 남아 있다.

대상은 [이전 진단](sac-short-update-20261118.md)의 seed0 온라인100회 모델이다.
B/gain0.001/Q0/actor LayerNorm 설정은 별도 비교 실험으로만 유지한다.
빠른 장면 `8b4c1e7e09f5f4c3`의 KEEP/FOLLOW, 저속 장면
`8a4fba3463c6c62d`의 KEEP에서 미학습/학습 후 두 주행 이력을 재현했다.
저속 FOLLOW, 다른 seed, 전체 validation의 일반화 검증은 이번 범위에 포함하지 않았다.

총6episode·363tick에서 저장된 이전 평가의 위치·속도·판정·제어 출처·종료와 대조했다.
위치/속도는 절대 오차1e-6 이내였고, 가속도·곡률 명령과 거절 위반 항목도 일치했다.
이전 학습/평가 결과를 새 정책의 성능으로 재라벨링하지 않았다.

## 동일 상태 비교 방법

미리 저장된 학습 주행의 거절 사유 변경 전후와10tick 간격을 검사 지점으로 정했다.
같은 검사 시각을 두 주행 이력에 적용하되, 먼저 종료한 이력의 이후 상태는 만들지 않는다.
총105개 상태·행동·주행이력 조합에서 다음3개 제안을 각각 검사했다.

- 평균0: 현재 측정 위치·속도·가속도에 기반한 기본 경로.
- 학습 평균: 저장된 온라인100회 actor가 해당 현재 관측으로 생성한 경로.
- Rule-based: 기존 Frenet 경로 생성기가 **동일 현재 상태**에서 생성한 경로.

Rule-based 제안은 이 검사에서 실행하거나 replay에 넣지 않았다. BC를 재도입한 것이 아니다.
세 제안은 같은 객체 snapshot·PD memory·지도·명령·검사 한계를 공유한다.
원래 검사기의 함수 호출을 관찰하고 반환값을 그대로 전달해 reference/virtual PD 단계를
구분했다. 환경 state/token/memory/old plan이 바뀌지 않았는지도 확인했다.

315개 제안 중95개가 거절됐으며,95개 모두 reference 단계에서 거절됐다.
이는 **선정한 상태의 제안 검사** 개수다. 독립 장면315개나 전체 학습 경로의 통과율이 아니다.

EMERGENCY를 포함해 기록했다. 이 수치를 고정3초 경로의 전체 RMS gate와 혼동하지 않는다.

## 빠른 장면: 미세한 경로 차이와 누적된 상태 변화

학습 후 KEEP 이력의20개 검사 상태에서 학습 평균8개, 평균0 경로10개,
Rule-based16개가 통과했다. 미학습 이력의 같은20개 시각에서는 각각19·19·20개였다.
FOLLOW도 같은 통과 개수와 주요 실패 순서를 보였다.

학습 이력의 **tick34, 실행 전3.4초**에 평균0과 Rule-based는 통과했지만 학습 평균은
거절됐다. 거절 사유는 가상 PD가 아니라 reference의 `PREDICTED_OFFROAD`였고,
첫 도로 위반 예상은 현재에서 약2.976초 뒤였다. 학습 평균과 평균0 경로의3초 끝점 차이는
약3.40cm였다. 실제 ego가 이미 도로를 벗어났다는 뜻이 아니다.

앞선 작은 제어 차이로 상태가 달라졌고, tick35부터는 같은 학습 주행 상태의 평균0 경로도
도로 검사에 실패했다. 반면 미학습 이력의 tick35에서는 학습 경로조차 통과했다.
이는 초기 상태 통과만으로 반복 재계획의 유효성을 판정할 수 없다는 직접적인 대조다.
작은 raw action만 강제하는 접근으로 충분하지 않다.

학습 이력의 tick1·34·35·36·38·39·40·44에서는 학습 경로가 거절되어도 Rule-based
제안은 같은 전체 검사를 통과했다. 이 사실은 그 상태에서 검사 가능한 다른 경로가
있었다는 근거이며, 해당 시각에 정책을 교체하면 반드시 성공한다는 증거는 아니다.

## 제동 후 거절이 지속되는 과정

빠른 KEEP의 tick44 제안은 도로 이탈 예상으로 거절됐고, 기존 경로는 만료됐으며
제동 후보도 도로 검사에 실패했다. 그 결과4.5초 상태로 진행하는 제어가 EMERGENCY였다.
다음 tick45 상태에서 실제 속도는10.472m/s, 측정 감속은 약6m/s²였다.

codec의 기본 경로는 `p + v*t + 0.5*a*t²`다. 이 측정 감속을3초 연장하면
평균0 경로의 끝점 전방 속도가 **-7.528m/s**, 학습 평균은 **-7.549m/s**가 된다.
학습 출력 최대 절댓값은 약0.000921로, 현재 운동 상태를 반영해 정지 이후까지 유효한
경로로 바꾸기에 부족했다. 같은 상태의 Rule-based도 가속도·jerk 위반으로 거절됐다.
어떤 경로도 존재하지 않는 상태라고 증명한 것은 아니다.

저속 KEEP에서도 tick29/30에 평균0은 통과하고 학습 평균이 도로 검사에 실패했다.
tick31까지 Rule-based는 통과했지만, 긴급제동 후 tick32/33에는 세 제안 모두 운동 검사를
실패했다. 정지한 tick40에는 평균0·Rule-based가 예상 충돌로, 학습 평균은 곡률 관련
위반으로 거절됐다. 실패 이유의 우선순위가 다르다고 안전 성공으로 재분류하지 않는다.

## 다음 개발 판단

PD·검사 한계를 바꾸거나 작은 gain 후보를 본 설정에 채택하지 않았다.
다음 단계는 이번 중간 상태들을 재현용 검사 사례로 사용해 **actor가 상태에 맞춰 경로를
수정하는지, Q의 행동별 평가와 actor 업데이트가 유효한 방향을 주는지** 점검하는 것이다.
긴급제동에 들어가기 전의 도로 제약과, 감속 이후의 경로 유효성을 함께 확인해야 한다.
이번에 저장한 Q값은 후보 평가 진단이며, 실제 수행하지 않은 경로의 수익을 검증한 값이 아니다.

보완 후보는 같은 실제 장면에서 회귀가 없는지 먼저 확인하고, 그 뒤 seed 확장과
장시간 학습을 진행한다. validation을 개발에 사용한 사실은 유지하고 독립 평가와 구분한다.
