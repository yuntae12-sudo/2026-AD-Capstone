이 실험은 무엇을 비교하나요?

두 SAC의 자기 경험 수집 방법을 비교하고, 주행 결과를 Rule-based와 대조합니다. 후보와 대조군 모두 강화학습이며 모방학습을 사용하지 않습니다.

같은 장면·명령·안전검사·PD 제어를 사용합니다. KEEP = 차로 유지, FOLLOW = 앞차 추종.

실제로 어떻게 주행했나요?

목표 도달은 높을수록, 충돌·거절·제동은 낮을수록 좋습니다. 정지 비중과 보상도 함께 봅니다.

정책평가 상태장면 / 주행목표 도달 ↑충돌 종료 ↓거절제동정지평균 보상

목표·충돌 종료: 평가 episode 기준. 거절·제동·정지: 실제 tick 기준. 정지 < 0.1m/s, 제동 = BRAKE + EMERGENCY. 미평가는 ‘—’. 표의 충돌은 종료 사유 기준이며 별도 이벤트 집계와 구분합니다.

현재 학습을 실시간으로 확인

웹 서버 터미널을 그대로 두고 새 터미널을 여세요. 저장소 폴더에서 아래 명령을 실행하면 됩니다.

모니터의 Ctrl+C는 화면만 종료합니다. 학습 중단 명령이 아닙니다.
새 학습 실행 방법 · 기존 실험 완료 후 사용
현재 도구는 기존 1,000회 모델 → 총 10,000회 이내의 재실험을 지원합니다. 마지막 10,000회 모델의 무제한 연장이나 새로운 seed 생성 기능은 아닙니다.
1. 학습 환경과 실행 계획 확인
먼저 저장소 폴더에서 conda activate its-merge를 실행하세요. 아래 명령은 학습을 시작하지 않습니다.
2. 학습 → 저장 검증 → 개발 평가 실행
기존 실험과 후속 작업이 끝난 뒤 실행하세요. 출력 폴더는 매번 새 이름을 사용합니다.
실행 터미널의 Ctrl+C는 학습도 중단합니다. 중간 checkpoint 재개는 지원하지 않으므로 최종 저장 전에 중단하면 해당 실행을 이어갈 수 없습니다. 웹 터미널의 Ctrl+C는 웹만 종료합니다.
로그 확인과 오래 실행하기
터미널 연결을 끊어도 계속하려면 tmux 세션 안에서 실행하세요. 결과와 단계별 로그는 지정한 outputs 폴더에 저장됩니다. 이 실행 도구는 학습·감사·평가까지 수행하며 기존 실험의 Q 진단·GIF 자동 생성은 포함하지 않습니다.
