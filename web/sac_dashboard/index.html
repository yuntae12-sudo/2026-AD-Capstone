내 터미널에서 실행하기

웹은 결과를 읽습니다. 학습 시작·중단은 터미널에서 직접 제어합니다.

현재 도구는 기존 1,000회 모델 → 총 10,000회 이내의 재실험을 지원합니다. 마지막 10,000회 모델의 무제한 연장이나 새로운 seed 생성 기능은 아닙니다.

1. 학습 환경과 실행 계획 확인

먼저 저장소 폴더에서 conda activate its-merge를 실행하세요. 아래 명령은 학습을 시작하지 않습니다.

2. 학습 → 저장 검증 → 개발 평가 실행
기존 실험과 후속 작업이 끝난 뒤 실행하세요. 출력 폴더는 매번 새 이름을 사용합니다.
실행 터미널의 Ctrl+C는 학습도 중단합니다. 중간 checkpoint 재개는 지원하지 않으므로 최종 저장 전에 중단하면 해당 실행을 이어갈 수 없습니다. 웹 터미널의 Ctrl+C는 웹만 종료합니다.
로그 확인과 오래 실행하기
터미널 연결을 끊어도 계속하려면 tmux 세션 안에서 실행하세요. 결과와 단계별 로그는 지정한 outputs 폴더에 저장됩니다. 이 실행 도구는 학습·감사·평가까지 수행하며 기존 실험의 Q 진단·GIF 자동 생성은 포함하지 않습니다.
